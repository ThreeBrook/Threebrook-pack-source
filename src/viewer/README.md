# 查看器、压缩 / 解压窗口与命令行工具

| 程序 | 位置 | 说明 |
|---|---|---|
| `iis-viewer.exe` | `src/viewer/` | 三溪缩影的图形查看器，以及资源管理器右键打开的压缩 / 解压窗口（Dear ImGui + Direct3D 11），单个 exe |

## 语言（中文 / English）

默认跟随 Windows 显示语言（中文系统用中文，其他用英文）；“视图 → 语言”可切换，命令行 `--lang zh|en`。
界面文字一律写成 `tr("中文", "English")`（`i18n.hpp`），带参数的用 `trf`。资源管理器右键菜单、文件类型名、开始菜单的文字
在 `icons.rc.in` 的两套字符串资源里，Windows 按显示语言选。命令行工具的输出仍是中文。

## 外观（三溪外观规范）

产品名“三溪缩影 / Threebrook Pack”，属于三溪（Threebrook）产品家族，外观照三溪外观规范（与三溪寻影、官网同一套）：

- `theme.hpp` / `theme.cpp`：规范的全部界面色（浅色 / 深色两套，默认跟随 Windows，“视图 → 外观”可固定；系统切换时立即生效）、
  主按钮（溪青实心，只给主要动作）、描边按钮、卡片（圆角 14）、提示条、状态徽章、进度条。界面上的产品名只从这里取。
- 字体：正文用系统的微软雅黑 UI；标题用站酷小薇（英文 Bricolage Grotesque）；路径、校验值、像素值用 JetBrains Mono。
  三个字体（SIL OFL 1.1，`assets/fonts/`）嵌在 exe 的资源里，许可证随安装包放在“许可证”文件夹。
- 自绘标题栏（高 36，左上图标 + 产品名 + 菜单，右边最小化 / 最大化 / 关闭，关闭悬停为 Windows 的红色）；
  拖动、双击最大化、贴边分屏照常（`WM_NCHITTEST`）。
- 看图区底色取画面平均颜色与页面底色的混合，不用纯黑。
- 图标：`tools/make_icons.py` 按三溪产品图标家族规则生成（柿橙圆角方块、白色主图案，64 像素及以上左下角带月亮签名）。
- `--render 截图.bmp --light | --dark`：不显示窗口，按指定外观截图（自检用）。
| `iis-cli` | `src/cli/` | 命令行：pack / unpack / list / info / verify / restore / compress / export（Windows 与 Linux） |
| `iis-decode` | `decoder/` | 独立开源解码器（BSD-3-Clause），见 `decoder/README.md` |

三者都只依赖操作系统自带的库（Windows：KERNEL32、USER32、GDI32、SHELL32、ole32、IMM32、d3d11、D3DCOMPILER_47，
windowscodecs，均为 Windows 10 / 11 自带），静态链接 C++ 运行库，**不需要安装 VC++ 运行库**；拷到任何目录即可运行。

## 绿色版打包

先运行 `scripts\ci-windows.ps1` 构建并测试，再运行：

```bash
powershell -ExecutionPolicy Bypass -File scripts\package-portable.ps1
```

得到 `dist\ThreebrookPack-<版本>-免安装版-win-x64\`（约 11 MB，查看器里嵌了三溪规范的字体）与同名 `.zip`：`iis-viewer.exe`、`iis-cli.exe`、`iis-decode.exe`、
`使用说明.txt`、`许可证\`（各开源组件许可证）。脚本会从打包目录里运行一次查看器自检，并确认运行后目录里没有多出任何文件。
整个目录拷到任何位置（含 U 盘）即可使用。`dist\` 不入库。

## 查看器

```bash
iis-viewer 文件或目录
```

- **免安装**：不写注册表、不写配置文件（界面布局也不保存）；没有显卡（虚拟机、远程桌面）时自动用 WARP 软件渲染；
  中文界面用 Windows 自带的微软雅黑（没有则黑体、宋体）。
- **打开**：`.iis`（在内存里还原并核对 SHA-256 后显示，界面标明“已还原并核对”）与原始 BMP、TIFF、RAW；
  格式按内容识别（与压缩用同一套识别），也可把文件拖进窗口。TIFF 多页可翻页。
  无文件头的 RAW 自动识别宽、高、像素格式后直接显示，界面标明“自动识别”，不对时可点“手动输入…”；
  识别不出来时弹出参数框（宽、高、像素格式、文件头字节、行字节）。
- **显示**：滚轮以鼠标为中心缩放、拖动平移，“适合窗口 / 1:1”；放大到 2 倍以上按像素显示（最近邻）；
  鼠标处显示坐标与原始样本值（Bayer 图还显示该像素的颜色）。
- **16 位窗宽窗位**：自动（0.1% / 99.9% 分位）、全范围、拖动调整上下限；显示用查找表，不改原始数据。
- **Bayer**：识别出的排列自动用于预览，也可手动指定；双线性去马赛克 + 可选灰度世界白平衡（只影响预览）。
- **目录浏览**：列表或缩略图（后台生成，不卡界面）。
- **包（.iisz）**：像文件夹一样浏览（包内只有一个顶层文件夹时直接进入），缩略图与看图都从包里取出并核对 SHA-256；
  “全部解压到此处”打开解压窗口。包内文件可“另存为原文件”。
- **其他图像**：PNG、JPEG、GIF 等用 Windows 自带的解码器（WIC）预览，只供查看。
- **批量还原**：文件 → 批量还原，或 `iis-viewer --restore [目录或 .iis 文件]`：把目录（可含子目录）或单个 `.iis`
  还原到输出目录，保持层次，逐个核对 SHA-256，已存在的不覆盖，`.iis` 保留不动。核心逻辑是 `restore_tree()`。
- **另存为原文件**：当前打开的 `.iis` 或包内文件可另存为原始格式。
- 超过 16384 像素的大图按整数倍抽稀显示（图像数据与像素值读数不受影响）。

## 资源管理器缩略图（iis_thumb.dll）

`.iis` 在资源管理器的“大图标”等视图里显示图片本身的预览，`.iisz` 包显示前 4 张图的拼图，而不是统一的图标。

- `thumb_provider.cpp`：Windows 缩略图处理程序（`IInitializeWithStream` + `IThumbnailProvider`）。
- 读取与查看器相同：在内存里还原并核对 SHA-256，按内容识别；16 位自动窗宽窗位，无文件头 RAW 自动识别；再缩到资源管理器要的大小。
- 安装包负责注册，见 `installer/README.md`。Windows 默认把缩略图处理程序放在隔离进程里运行，出错不影响资源管理器。
- 每次调用都捕获所有异常；还原失败、文件损坏或超过 2 GB 时返回失败，资源管理器改显示图标。
- `.iisz` 包显示前 4 张图的拼图（`image.cpp` 的 `package_mosaic`）：只读包的目录和这几张图的条目，不读整个包；按“层次浅的在前、同层按名称”挑，跳过子包、非图像文件和超过 256 MB 的文件，最多试 12 个。4 张拼 2×2，3 张左一右二，2 张左右并排（各自居中裁满格子），1 张按原比例；格子之间的缝透明。包的缩略图右下角叠加包图标（ProgId 的 `TypeOverlay`），与单张图区分；包里没有能显示的图像时显示包图标。查看器左栏里包的格子用同一个拼图。

测试：`iis_thumb_check` 像资源管理器那样调用 DLL（不注册、不需要管理员），检查以下各项，CI 每次运行：
- 256 与 96 两种尺寸；
- 内容正确；
- 损坏的 `.iis` 返回失败；
- 全部释放后可以卸载。

## 压缩 / 解压窗口（资源管理器右键）

```bash
iis-viewer --compress 文件夹或文件…
```

```bash
iis-viewer --extract 包.iisz、文件.iis 或文件夹…
```

- 压缩：文件夹 → 旁边的 `文件夹名.iisz`（格式见 `spec/package-v1.md`）；单个文件 → 旁边的 `文件名.iis`。
  开始前列出每项会生成什么，可勾选“压缩并核对后删除原文件”（默认保留）。
- 解压：直接开始。`.iisz` 解到包旁边（同名文件夹已存在时加 (2)），`.iis` 还原到旁边，文件夹则解开其中所有的 `.iis` 与 `.iisz`。
  已存在的文件一律不覆盖。
- 显示进度、每项结果与压缩比；可取消（打包取消时不留下任何文件）；完成后可“打开文件夹”。
- 资源管理器选中多项时为每一项各启动一次本程序：第一个进程建一个收集窗口，其余进程用 `WM_COPYDATA` 把路径交给它后退出，
  所以只出现一个窗口。
- 没给路径时（开始菜单“三溪缩影 压缩文件夹”“三溪缩影 解压”）先弹出选择框。
- 任务逻辑在 `iis_view` 库的 `tasks.cpp`（`run_compress`、`run_extract`），与界面无关，有单元测试。

自检 / 测试用：`iis-viewer --render 截图.bmp [--size 1280x800] [文件或目录]` 不显示窗口，读取完成后把界面存为 BMP 并退出
（Windows 本地 CI 每次运行，含压缩窗口）。

## 命令行 iis-cli

不依赖后台服务，可用于任何目录（含拷出来的 U 盘、移动硬盘）。

| 命令 | 说明 |
|---|---|
| `iis-cli info 文件.iis…` | 原文件大小与 SHA-256、原格式、压缩比、各段 |
| `iis-cli verify 文件、目录或包… [-r] [--deep]` | 结构与每段 CRC；`--deep` 再完整还原并比对 SHA-256（`.iisz` 同样适用） |
| `iis-cli restore 文件或目录… [-r] [-o 输出目录]` | 还原为原文件（SHA-256 一致才写出，已存在不覆盖）；`-o` 时保持目录层次 |
| `iis-cli pack 文件夹… [-o 包.iisz] [--delete]` | 每个文件夹打成一个包（默认在文件夹旁边，保留原文件；`--delete` 核对后删除原文件） |
| `iis-cli unpack 包.iisz… [-o 输出目录]` | 解包：默认解到包旁边（同名文件夹已存在时加 (2)），已存在的文件不覆盖 |
| `iis-cli list 包.iisz…` | 列出包内文件、原大小与包内大小 |
| `iis-cli compress 文件或目录… [-r] [--release] [--rules 规则.json] [--min-saving 0.05]` | 逐个压缩为同目录的 `.iis`（原子提交；默认保留原文件；不需要授权） |
| `iis-cli export 源目录 输出目录 [--copy] [--from 日期] [--to 日期] [--include 通配]…` | 批量导出：默认 `.iis` 还原为原格式、其他照抄；`--copy` 原样复制 |

退出码：0 全部成功，1 有失败，2 用法错误。
