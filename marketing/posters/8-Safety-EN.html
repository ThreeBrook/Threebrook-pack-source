Threebrook Pack

Data safety comes
before compression ratio.

Every file is decoded and compared right after compression, before it is written.
If any step disagrees, the file is stored as it is — your data is never dropped or altered.

1

Detect the format from content

Headers and key fields decide BMP / TIFF / RAW / Bayer, bit depth and layout — not the file extension.

2

Lossless, standard code streams

Pixels are encoded with open standards such as JPEG-LS; headers, palettes and padding bytes are kept as they are.

3

Decode and rebuild on the spot

Right after compressing, the file is decoded and reassembled into the original byte sequence.

✓

Compare SHA-256, keep only a match

Mismatch, no size gain, or an unknown format:

automatically falls back to generic compression or stores the file as is
Byte for byteNot “looks the same” — every byte of the file is identical
Open.iisz is a standard ZIP; the decoder iis-decode is open source
