Threebrook Pack

Works like ZIP.
Understands images better than ZIP.

Four steps: compress, browse, preview, extract.

01

Right-click to compress

A folder becomes one .iisz package, a single image an .iis. Originals are kept by default.

02

Look inside the package

Double-click a .iisz and browse it like a folder. Click an image to view it — no unpacking first.

03

Recognise at a glance

In File Explorer a .iis shows the image itself; a .iisz shows a mosaic of its first four images.

04

Extract, byte for byte

Every file is checked with SHA-256 and matches the original exactly. Existing files are never overwritten.
