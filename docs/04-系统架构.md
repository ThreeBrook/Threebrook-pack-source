# 04 系统架构

> 状态：硬件形态**未最终确定**，本文档列出选项与当前倾向。

## 1. 压缩放在链路的哪个位置

```
相机 ──► 视觉工控机 ──(网络)──► 存储服务器/NAS ──► 归档
  ①          ②                ③                ④
```

| 位置 | 形态 | 优点 | 缺点 | 结论 |
|---|---|---|---|---|
| ① 相机/采集卡 | 采集卡上压缩 | 最早压缩 | 动客户取图链路，绑定相机接口 | 排除（不做相机） |
| ② 工控机内 | PCIe 加速卡 / 软件代理 | 连网络带宽一起省 | 每台都要装；Windows 驱动 / 文件过滤；碰客户视觉软件 | 第二代 |
| ③ 网络网关 | **压缩存储一体机** | 零侵入，改保存路径即可；一台服务整条线 | 网络上传的仍是原图，工控机网口可能是瓶颈 | **当前倾向，首发** |
| ④ 存储端后处理 | 纯软件装在客户服务器/NAS | 不卖硬件 | 峰值容量仍按原图准备；性能看客户机器 | 低价版 / 试用版 |

## 2. 一体机数据流：先落盘、再压缩

```
工控机 ─SMB/NFS─► [NVMe 落地缓存] ─► [后台压缩 + 解码自校验 + SHA-256] ─► [HDD 阵列]
                     (收到即确认写入)        (CPU/GPU 线程池)               (只存压缩后数据)
                                                    │
                                            校验通过才删缓存原图
```

好处：写入延迟稳定（压缩快慢不拖产线）；缓存吸收换班、补拍等峰值；校验通过前原图一直保留，断电或出错不丢图。

读取：命中缓存直接返回；否则解码 + 按配方重组原文件。读取速度需达到原图读取水平（AI 重训场景）。

## 3. 参考配置（单台约 1 GB/s）

| 部件 | 配置 | 理由 |
|---|---|---|
| 机箱 | 4U 24 盘位，或 2U 网关 + 外接 JBOD | 容量灵活 |
| CPU | 32~48 核 x86 | JPEG-LS 单核约 100~200 MB/s；编码 + 校验解码，1 GB/s 约需 16~20 核 |
| 内存 | 256 GB ECC | 必须 ECC，防静默坏图 |
| 落地缓存 | 2 × 7.68 TB 企业级 NVMe 镜像，**带掉电保护（PLP）** | 1 GB/s 下缓冲约 2 小时 |
| 网络 | 2 × 25GbE | 一路接产线，一路供 MES/AI 调取 |
| 硬盘 | 24 × 20 TB HDD，RAID6 | 可用约 400 TB，2.5 倍压缩约等效 1 PB |
| 加速（可选） | 1 块 GPU 跑 HTJ2K | >1 GB/s 或多产线时 |
| 电源 | 冗余电源 + UPS 联动 | 存储设备底线 |

不含硬盘 BOM 约 5~7 万元（2026 年 NVMe 涨价明显）。

## 4. 销售形态（待决策）

| 模式 | 毛利 | 风险 |
|---|---|---|
| A. 只卖网关，后端挂客户 NAS/盘柜 | 高 | 性能受客户存储影响 |

## 5. 软件模块

| 模块 | 职责 |
|---|---|
| `ingest` | SMB/NFS 接入、落地缓存管理、写入确认语义 |
| `detect` | 按内容识别格式：魔数、位深、压缩状态、Bayer 检测、RAW 参数推断 |
| `layout` | 版面整理：行序、行填充、字节序、解包/打包、移位、Bayer 拆分（全部整数、可逆） |
| `codec` | JPEG-LS / HTJ2K / JPEG XL / zstd 统一接口 |
| `container` | 压缩文件容器读写（见 `05` 容器草案） |
| `verify` | 编码 → 解码 → 重组 → SHA-256 比对；失败回退 |
| `store` | 落盘、RAID 之上的对象布局、垃圾回收 |
| `serve` | 读取还原、热数据缓存、批量解码接口（对接 AI 训练） |
| `index` | 元数据索引：时间、工位、批次、OK/NG、文件哈希 |
| `policy` | 分级存储策略、保留期、降级（可选功能），带审计日志 |
| `console` | Web 管理台：物理用量 / 等效容量、压缩比、吞吐、告警 |
| `tools/decoder` | 独立开源解码器（客户不依赖设备也能还原） |

## 6. 现场注意事项

1. **工控机网口**：4 台相机 × 每秒 20 张 × 5MB ≈ 100 MB/s，打满千兆。很多产线需先升万兆，要写进方案。
2. **安放位置**：产线旁粉尘、高温、振动不适合机械硬盘，放机房或带空调的工业机柜。
3. **SMB 兼容性**：Windows 工控机为主，重点测 SMB3、权限、长路径、海量小文件。这里比算法更容易出问题。
4. **读取算力**：还原同样占 CPU，需预留。

## 7. 第二代：工控机侧加速卡（触发条件）

- 客户网络带宽成瓶颈且不愿升级；或
- 单条产线 > 3~5 GB/s，网关需叠很多台。

难点在软件：Windows 上拦截视觉软件写文件、兼容 Halcon/VisionPro 等保存方式。JPEG-LS FPGA IP 可采购（Alma、logicBRICKS）。
